# Тесты

- `contracts/` — общие тесты на формы данных и контрактные инварианты.
- `unit/` (добавить при необходимости) — тесты алгоритмов конкретных реализаций.
- `integration/` (добавить при наличии API симулятора) — проверки обмена между адаптерами.

Для каждой альтернативной реализации одного типа должен выполняться один и тот же контрактный набор тестов.
