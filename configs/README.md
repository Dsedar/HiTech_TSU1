# Конфигурации

- `default.yaml` — общая конфигурация выбора реализаций и режима.
- Не храните здесь пароли, токены или персональные данные.
- Конфигурация не должна менять контракт модулей; она выбирает реализацию и параметры.
- Для локальных параметров используйте `local.yaml` и добавьте его в `.gitignore`.
