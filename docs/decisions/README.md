# Architecture Decision Records (ADR)

Здесь фиксируются решения, которые влияют на нескольких участников: система координат, единицы, протокол обмена, правила выбора участка, схема статусов, политика тайм-аутов и структура плагинов.

Рекомендуемое имя: `0001-local-coordinate-frame.md`. Каждая запись должна содержать контекст, принятое решение, альтернативы и последствия.
