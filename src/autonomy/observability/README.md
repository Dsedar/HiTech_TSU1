# Observability

Планируемое место для структурированных логов, событий этапов, метрик времени и итогового отчёта попытки.
Рекомендуется логировать: `run_id`, `module_name`, `module_version`, `status`, длительность, причину ошибки и идентификатор выбранного участка.
Не записывайте секреты. Для сопоставимости экспериментов сохраняйте Git commit SHA и имя конфигурации.
