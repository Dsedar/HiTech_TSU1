# Adapters

Здесь размещаются тонкие адаптеры к внешним системам:

- API веб-симулятора;
- ROS 2 topics/services/actions;
- видеопоток/камера;
- бортовые вычислители и телеметрия;
- транспорт сообщений между платформами.

Адаптер отвечает за преобразование внешнего формата в `contracts.models` и обратно.
Не размещайте здесь алгоритмы обнаружения, выбора цели или планирования.
Реальный API веб-симулятора добавляйте только после получения его документации.
